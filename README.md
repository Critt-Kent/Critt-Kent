
# This is the Github page of for the Center for Research and Innovation in Translation and Translation Technology (CRITT) at Kent State University. 

### The primary aim of the research carried out at CRITT is to build up new knowledge of translation and communication processes and provide a basis for technological innovation in this field.

CRITT updates and maintains a database of behavioural translation data of keystroke and gaze data.
It provides access to number of python notebooks to access the data in CRITT database and to understand or analyse translation behavior.
